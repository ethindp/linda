# Upstream unit tests that tests/linux/rununittests.py does not expect to pass on Linux.
# A dotted name under tests.unit at the start of a line is an exclusion. The indented lines beneath
# it say why, and the first of them starts with "For good", for a test of code that exists only on
# Windows, or with "Until", naming what has to change for it to pass. One of the lines beneath also
# states what is expected, and the runner fails the run once that no longer holds:
#   "Raises: " an exception class name, ": " and a fragment of its message. Every test the entry
#   covers runs, and its first failure must be such an exception, found anywhere in the exception's
#   class hierarchy and chain of causes. An entry may name a module, a class or a single test.
#   "Import raises: " the same, for a module or package that cannot be imported. It is never imported
#   into the run; a process of its own imports it, and every test module it covers must fail to
#   import with such an exception.
#   "Not run: " and why running the tests would do harm, for a class or a single test only. They are
#   dropped.
# A line that starts with "skipped" and a dotted name lists tests the run may skip; any other skip
# fails the run. The runner also fails on an entry that matches nothing.
